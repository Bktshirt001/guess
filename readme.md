# 猜数字小游戏说明

这是一个基于 Rust 编写的命令行猜数字程序，核心功能非常直接：程序启动后会在 1 到 99 之间随机生成一个目标数字，然后进入持续输入的猜测循环。用户每次输入一个数，程序都会读取控制台中的内容，并与随机生成的答案进行比较。

当用户输入的数字等于系统给出的目标值时，程序会输出“恭喜您，猜对了！”，表示本轮游戏成功结束；如果输入的数字比目标值大，程序会提示“您输入的数太大了！”；如果输入的数字比目标值小，则会提示“您输入的数太小了！”。在每次判断之后，程序还会再次显示“您输入的数是：…”，方便用户确认自己刚刚输入的内容。

从功能上看，这个程序属于一个典型的单人终端小游戏。它的亮点在于随机数生成、用户输入读取、数值大小比较和循环反馈机制都已经完整组合在一个简洁的命令行界面内，适合初学者学习 Rust 基础语法、标准输入输出、字符串处理以及循环结构的使用方式。

同时，这个项目也体现了一个很典型的学习型 CLI 程序特点：代码量不大，但覆盖了最常见的编程逻辑。用户只需要在终端中运行程序，就可以直接体验一次“猜数字”的互动流程。程序没有复杂的界面，也没有额外的文件存储或用户登录，考察的是纯控制台交互的即时反馈能力。

如果把它作为 Rust 入门项目来看，它非常适合作为从“控制台输入输出”走向“逻辑判断与循环”这一阶段的示例。它展示了如何通过 Rust 读取用户输入、使用随机数库生成目标值、比较不同数值并根据结果给出反馈。这类程序的价值不仅在于“能玩吗”，更在于它能够帮助学习者理解命令行应用的基本构成方式。

总体来说，这个项目可以概括为一个简洁而实用的随机猜数字终端小游戏。它的运行方式简单、代码结构清晰、交互逻辑直观，适合用于 Rust 入门练习、课堂演示或个人学习记录。
